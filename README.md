## 🚀 About the Project

**DRAWIFY** is a real-time collaborative drawing application that allows users to create or join rooms and communicate visually using drawings, shapes, and sketches — all synchronized live across participants.

The goal of DRAWIFY is to make visual communication simple, interactive, and engaging.

---

## ✨ Key Features

- 🖌️ Real-time collaborative drawing  
- 👥 Create and join multiple rooms  
- 📐 Draw shapes and freehand sketches  
- 🔄 Live canvas synchronization  
- ⚡ Smooth and responsive UI  

---

## 🧰 Tech Stack

- **Frontend:** React.js  
- **Backend:** Node.js, Express  
- **Real-time Communication:** WebSockets  
- **Styling:** CSS / Tailwind CSS  
- **State Management:** React Hooks  

---

## 📦 Installation & Setup

### Clone the Repository

```bash

git clone https://github.com/MonishPuttu/DRAWIFY.git

cd DRAWIFY
```
Install Dependencies
```
pnpm install
```
Run the Application
```
pnpm run dev
```
---

### 🧪 How to Use

- Open the application

- Create a new room or join an existing one

- Start drawing on the canvas

- Invite others to collaborate in real time
